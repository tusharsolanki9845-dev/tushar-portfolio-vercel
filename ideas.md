# Tushar Solanki Portfolio — Reference Ground Truth

The attached `tushar-portfolio.zip` is the reference specification for the revised portfolio. The active build should retain its responsive React structure while adopting the reference's content model, dark build-log tone, compact developer tooling language, and direct personal positioning.

## Reference-led direction

**Design Movement:** Dark editorial developer build log, combining a product changelog, code editor panel, and project case-study archive.

**Core Principles:** Make shipped work the proof; keep the interface information-dense but readable; use status, stack, and deployment metadata as visual language; prioritize fast, honest, low-cost engineering over decorative abstraction.

**Color Philosophy:** A near-black canvas and blue-charcoal panels create a calm technical base. Amber communicates action, progress, and the human craft behind the work; mint-green is reserved for live/open status. Muted gray-blue text keeps the page legible without flattening the hierarchy.

**Layout Paradigm:** Use full-width horizontal bands for the hero, count-up stats, skills, build log, résumé, and contact. Inside each band, favor editorial two-column compositions, structured data panels, and stacked case-study rows rather than centered marketing cards.

**Signature Elements:** A faint 72px technical grid texture; JetBrains Mono microcopy with `>_` and slash-style metadata; browser-window panels with amber/mint status lights and thin amber rules.

**Interaction Philosophy:** Interactions should feel like a developer tool: precise, quick, and visibly stateful. Use scroll reveal for section entrances, count-up numbers for proof points, a typewriter role line for current work, status dots for project state, and hover borders/lifts for inspectable cards.

**Animation:** Keep movement under 600ms, driven by opacity and transform. The status dot may pulse for live work, the role line types in one phrase at a time, and the stats count only once when their strip enters view. Respect reduced-motion preferences.

**Typography System:** Space Grotesk is the display face for large statements and project names; Inter carries readable paragraphs; JetBrains Mono handles nav, labels, chips, metadata, and status values. Use tight letter-spacing on display headlines and generous tracking on uppercase labels.

**Brand Essence:** Tushar Solanki is a B.Tech CSE (AI & ML) student and freelance web developer who ships useful e-commerce, civic-tech, and SaaS products for real users. Personality: practical, curious, self-directed.

**Brand Voice:** Direct, builder-first, and specific. Headlines should make a clear claim; supporting copy should name the users, constraints, or outcome. Examples: “I ship things people actually use.” and “A running log of what I’ve shipped — client work and personal builds alike.”

**Wordmark & Logo:** Use the restrained monospace wordmark `tushar.dev` with the `.dev` portion in amber instead of a generic badge. The browser-window profile panel is the companion brand device.

**Signature Brand Color:** Amber `#e8a33d`, balanced by mint `#4fbda6` for live/open states.
